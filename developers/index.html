    For developers and AI agents

    Everything on InMyCal is free to read: no key, no account. Times are UTC.

    MCP server

    Streamable HTTP endpoint: https://inmycal.com/mcp. Tools: list_competitions, list_teams, find_events.

    JSON API

    GET https://inmycal.com/api/v1/events?competition=premier-league&from=2026-11-01&to=2026-11-30

    Also /api/v1/competitions and /api/v1/teams?competition=la-liga. Full description: openapi.json.

    Calendar feeds

    https://inmycal.com/cal/<competition>.ics and https://inmycal.com/cal/<competition>/<team>.ics (iCalendar, subscribe by URL). Event UIDs never change.

    Fair use

    Cache results for a few minutes; feeds change at most a few times a day. Sources: openfootball (public domain), sportstimes/f1 (MIT), Wikipedia (CC BY-SA).
